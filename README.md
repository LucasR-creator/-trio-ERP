# Átrio ERP — Sistema de Gestão Empresarial

**Uma plataforma de gestão empresarial moderna, desenvolvida com Python, FastAPI, JavaScript, HTML, CSS e banco de dados SQL.**

O **Átrio ERP** é um sistema de gestão empresarial desenvolvido para centralizar e organizar operações de pequenas e médias empresas em uma única plataforma.

O projeto apresenta uma interface moderna, responsiva e intuitiva, com módulos integrados para gerenciamento de produtos, estoque, vendas, clientes, fornecedores, finanças e processos administrativos.

## 🚀 Funcionalidades

- **Dashboard:** indicadores empresariais, gráficos e visão geral das operações.
- **Gestão de produtos:** cadastro, edição, consulta e organização de produtos.
- **Controle de estoque:** acompanhamento das quantidades disponíveis, estoque mínimo e movimentações.
- **Vendas e pedidos:** registro de vendas, seleção de produtos e atualização do estoque.
- **Gestão financeira:** controle de receitas, despesas e movimentações financeiras.
- **Clientes e fornecedores:** cadastro e gerenciamento de informações comerciais.
- **Gestão de filiais:** organização de diferentes unidades empresariais.
- **Funcionários e serviços:** gerenciamento de registros administrativos.
- **Relatórios:** acompanhamento de indicadores e exportação de informações.
- **Autenticação:** cadastro de empresas, login e controle de sessões.
- **Notas fiscais:** registro de informações fiscais, sem transmissão oficial aos órgãos competentes.

## 💻 Como executar o projeto

### Pré-requisitos

- Python 3.11 ou superior
- Visual Studio Code ou outro editor
- Navegador atualizado
- Git (opcional)

### Instalação

**1. Clone o repositório:**

```bash
git clone https://github.com/SEU-USUARIO/atrio-erp.git
```

Substitua `SEU-USUARIO` pelo seu usuário do GitHub.

**2. Acesse a pasta do projeto:**

```bash
cd atrio-erp
```

**3. Execute o inicializador no Windows:**

```cmd
iniciar_windows.bat
```

O inicializador prepara o ambiente Python e instala as dependências necessárias.

**4. Abra o sistema no navegador:**

- Site: http://127.0.0.1:8000
- Painel administrativo: http://127.0.0.1:8000/painel
- Documentação da API: http://127.0.0.1:8000/docs

## 🔐 Segurança e armazenamento

O sistema possui autenticação de usuários, proteção de senhas e persistência dos dados empresariais em banco de dados.

Também foi desenvolvido um mecanismo de backup para criar cópias de segurança do banco SQLite, com possibilidade de integração a pastas sincronizadas com serviços de armazenamento em nuvem.

**Importante:** bancos de dados reais, credenciais, tokens e backups privados não devem ser publicados no GitHub.
